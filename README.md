# 数据结构第 3 章：栈与队列代码演示

这是一个标准 C++17 / CMake 项目。用 CLion 打开**本目录**，等待 CMake 加载完成，在右上角选择任意 `demo_01` 至 `demo_23` 运行配置即可。每个中文命名的 `examples/*.cpp` 都有独立的 `main`，互不依赖运行顺序，也无需输入。

代码根据所给 PPT 的知识点重新设计，没有复制其中的伪代码。数据结构的元素统一使用 `int`；表达式、编辑器、汉诺塔等题目本身需要字符时才使用 `char` 或 `std::string`。项目没有使用 `typedef` 或类型别名。空栈、空队列返回 `std::optional<int>`；定长容器满时返回 `false`。内存由标准容器或智能指针管理。

## 运行与检查

CLion：`File > Open` 选择此目录，等待 CMake 加载，选中目标后运行。项目使用 CLion 自带的 CMake 即可。

命令行（如果已安装 CMake）：

```sh
cmake -S . -B build
cmake --build build
ctest --test-dir build --output-on-failure
```

每个演示目标都注册为 CTest 检查项；`core_checks` 另检查边界条件与算法结果。

每组知识点按“`.h` 声明 + `.cpp` 实现 + 若干演示 `.cpp`”组织：

| 声明 | 实现 | 演示 |
| --- | --- | --- |
| `include/栈.h` | `src/栈.cpp` | 01–04，其他应用也会调用 |
| `include/队列.h` | `src/队列.cpp` | 15–19，队列应用也会调用 |

CMake 将四个实现文件编译为 `chapter3_core` 库，所有演示和测试目标都链接这个库。演示文件只放示例输入、调用和结果展示。

## 实现约定

- `FixedStack` 中的 `size_` 指向下一个空槽；满条件是 `size_ == capacity`。
- `CircularQueue` 内部申请 `capacity + 1` 个槽，留一个槽区分空与满。对外容量仍为 `capacity`。
- `CountingQueue` 使用长度计数区分空与满，恰好申请 `capacity` 个槽。
- `LinkedQueue` 使用头结点。最后一个元素出队后，尾指针必须重新指向头结点。
- 表达式支持十进制整数、`+ - * /`、括号、空格以及直接写在数字前的负号，例如 `-8+5*2`。除法为 C++ 整数除法，向零截断。非法表达式、除零及整数溢出会抛出异常。`-(2+3)` 这种括号前的一元负号不在本演示范围内。
- k 阶斐波那契示例接受 `k >= 2`、`max >= 1`；演示输出所有不超过 `max` 的项、最后 k 项以及首个超过 `max` 的下一项。输出项保持在 `int` 范围内。
